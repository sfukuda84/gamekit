## アートディレクション

- **トーン**: プレイヤーに与えたい印象を 3 語以内で（例: 乾いた、無骨な、ユーモラス）。デザインの柱（`docs/game/pillars.md`）との対応
- **アートの形式**: 例: ドット絵（基準の解像度、1 ドットの大きさ）/ 2D の手描き / ローポリの 3D
- **参考にする作品**: 名前と、参考にする点・しない点（`docs/research/competitors.md`。オマージュ元の固有の見た目をそのまま持ち込まない）
- **素材の作り方と置き場所**: 自作 / 外注 / 有料の素材（ライセンスは `docs/nfr.md` の NFR-CO に従って記録する）

## 色

| 役割 | トークン | 使いどころ |
|---|---|---|
| UI の背景 | `color.ui.surface` | ウィンドウ、メニューの背景 |
| UI の文字 | `color.ui.text` | 本文 |
| 強調 | `color.ui.accent` | 選択中の項目、重要な数値 |
| 危険 | `color.status.danger` | 体力の減少、警告 |
| 回復・良い変化 | `color.status.positive` | 回復、収入 |

- **パレットの方針**: 例: 画面の色はアートのパレットから選び、UI の色はトークンで別に持つ
- **コントラスト**: 文字と背景は 4.5:1 以上（`EXPERIENCE.md` の「アクセシビリティ」の水準に従う）。ゲームの画面の上に重ねる文字は、背景の板か縁取りを付ける

## 文字

| 役割 | トークン | 使いどころ |
|---|---|---|
| 書体 | `font.family.base` | UI の文字 |
| 本文 | `font.size.body` | メニュー、説明 |
| 見出し | `font.size.heading` | 画面の見出し |
| HUD の数値 | `font.size.hud` | 体力、所持金など |

- **書体の方針**: 例: ドット絵に合うビットマップのフォント（ライセンスを確かめる）。日本語と英語の両方の字形があるか
- **多言語**: 対応する言語と、文字の長さが変わったときの扱い（`EXPERIENCE.md` の「言語とローカライズ」）

## レイアウトと余白

- **基準の解像度と拡大の方法**: 例: 640×360 を整数倍で拡大する / 1920×1080 を基準に縦横比を保つ
- **セーフエリア**: テレビやスマートフォンの切り欠きで隠れない範囲
- **余白の段階**: `space.1`〜`space.4`
- **HUD の配置の方針**: 画面のどこに何を置くか（中央はプレイの邪魔をしない、など）

## してよいこと・してはいけないこと

- **する**: 例: UI の色と文字の値は必ずトークンから使う。ゲームパッドで選んでいる項目が常に分かる
- **しない**: 例: 色だけで状態を伝えない。プレイ中の画面の中央に UI を重ねない
