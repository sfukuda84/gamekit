# アイデア帳（backlog）

採らなかった案（壁打ち、方向性の比較、実装中の思いつき）と、`docs/feature/` にまだ機能化していない候補を置く場所。`gamekit-sparring` が作り、`gamekit-features` が足す。様式は `gamekit-features` の validate.py が検査する。
`gamekit-features --backlog <ID>` で、候補を `docs/feature/NNN-<slug>.md` として機能化できる。

## 運用ルール

- 状態は **候補 / 機能化済み（docs/feature/NNN-slug.md） / 却下** のいずれか
- 候補は消さない。機能化・却下したら状態欄を書き換える。却下したものを復活させるときは、状態を「候補」に戻して理由を追記する
- 要件概要は**広く浅く**書く（クラス名・データの項目・具体的な数値は書かない）
- 手で候補を足してよい。ID は既存の最大値の次から振る
- 「機能化するときに決めること」は、機能化するときのヒアリングの最初の論点になる
